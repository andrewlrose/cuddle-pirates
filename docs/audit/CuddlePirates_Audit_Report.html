CuddlePirates — Audit Report

Fable creative/business portfolio audit — deep pass, 2026-07-07. Supersedes the 2026-07-07 19:36 shallow draft.

Executive Summary

CuddlePirates is a CREATIVE/SOFTWARE hybrid, but heavily weighted creative: the "software" layer is a stub package.json (v0.0.1, no scripts, no dependencies) and an index.html, while the substance is a 1,266-line story bible, a curated 97-image Midjourney concept inventory, storyboards, a spec script, and pitch analysis — all serving its role as the first demo IP proving out Volta's pipeline for a Q3 2026 pitch. The project's documentation discipline is unusually good (locked decisions recorded, open blockers explicitly listed, "do not invent answers" rules). The deep findings are about drift and weight: the bridge manifest declares only Volta, with no Writers_Room wiring despite ADR-0009 expectations; the repo carries ~805MB with 258 images/zips tracked in git — including an apparently duplicated docs/CuddlePirates_updates/ snapshot — against the project's own "reference, don't duplicate" rule; family email files (.eml) are only half-quarantined, with the deletions still uncommitted; and the story bible's own status contradicts CLAUDE.md's "placeholder until Section G" rule. Per audit guardrails, no narrative content was touched — everything below is flag-only.

Plain-language layer, finding by finding

  • CP-1: This project was supposed to plug its story decisions into the family's shared story engine, which enforces "a human must approve everything." Instead the story lives in plain files with no approval trail. Fine for now — but every month of drift makes plugging in later more painful. Pick a lane deliberately.
  • CP-2: The project folder weighs nearly a gigabyte because concept images live inside it — including the same batch stored twice (zipped and unzipped). The project's own rulebook says images should be referenced from OneDrive, not copied in. Nothing was deleted; that's a human call.
  • CP-3: Real family emails are in this repo. Someone already started moving them to a quarantine folder — but the move was never finished, and git remembers everything ever committed. If this repo is ever made public, the emails come with it. Finish the move; keep the repo private.
  • CP-4: The instruction file says "the story bible is empty placeholder," but the story bible contains a locked five-character cast and hundreds of lines of world-building. Both can't be true. Also: one locked answer says "use MetaHuman" (photoreal tech) while the locked art style is soft storybook — flagged by the project itself, still unresolved.
  • CP-5: The image catalog was built to identify pictures by fingerprint so they survive being moved — but the fingerprints were never filled in. A padlock with no key cut yet.
  • CP-6: Every piece of the show's visual identity traces to one cloud folder named "Backup_2023oct22." One folder, one account, no second copy. Cheap fix: copy it to the family backup drive.
  • CP-7: The pitch art is AI-generated and the characters are affectionately based on real relatives. Before showing outsiders, write one paragraph on who owns what and that the family's fine with the likenesses.
  • CP-8: Some files show as changed in ways that may be the known Windows/Linux illusion. One native git status sorts it out.
  • CP-9: Genuine compliment: this project writes down its decisions, open questions, and rules better than most professional productions.
